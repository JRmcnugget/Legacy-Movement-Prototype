# Legacy-Movement-Prototype
Early prototype archive of a first person movement system in LuaU, created when I first began experimenting with more complex systems and interactions. I did not have anything particular in mind as this project was more of a learning experience, so the code is unorganized and unmaintainable. For historical reference only, please use something more scalable than this

Features:
- Dynamic aim assist via scaling hitboxes along with distance
- Rudimentary viewport model and animations
- Crouching & crouch sliding
- Wallrun and wallclimb
- Morph ball mode
- Dashing with strength based on stamina consumption
- Grapple ability
- Lunge ability to specific targets
- Assorted player interactions (water traversal effects debuffs and post processing, breakables, tutorial prompts, camera override, damage, collectables)
